## Обоснование: почему #4 и #8 выигрывают у #15?

### По бизнесу
- **#4:** Управление резервами = требование регулятора (обязательно)
- **#8:** Retention = прямой ROI (если сохранить 1% клиентов = X млн ₽)
- **#15:** Оптимизация смен = косвенный результат (экономия на зарплате, но меньше чем ROI #4-#8)

### По техническому риску
- **#4:** Регрессия на табличных данных = стабильная задача
- **#8:** Классификация на табличных данных = стабильная задача (есть LightGBM/XGBoost)
- **#15:** Временной ряд = требует специализацию (ARIMA, Prophet, LSTM)

### По готовности данных
- **#4:** 5 лет истории, полная разметка (дефолт / норма) ✅
- **#8:** История активности клиентов, целевая переменная = ушел/остался ✅
- **#15:** Только операционные данные, нет явной целевой переменной ⚠️

### По объему работы
- **#4:** 2-3 недели (данные → разметка → модель)
- **#8:** 2-3 недели
- **#15:** 4+ недели (требует анализ сезонности, лагов, праздников)
