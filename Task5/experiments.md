# План экспериментов по улучшению

## Эксперимент 1: Новые примеры обналичивания (ОСНОВНОЙ)

### Неделя 1-2: Подготовка данных

- Собрать 200 операций обналичивания (Jul-Aug 2024)
- Переразметить экспертом (качество критично!)
- Double-blind validation на 50 примерах (Cohen's kappa > 0.75)

### Неделя 3: Обучение

- Добавить в training set
- Переучить LightGBM
- Оценить на ВАЛИДАЦИИ (не production!)

### Неделя 4: Проверка результата

**Диагностический набор:** 20 примеров

**GO/NO-GO:**
- GO: Precision обналичивания >= 58%
- NO-GO: Precision < 50% (данные не помогли)

## Эксперимент 2: Функция ошибки (ПАРАЛЛЕЛЬНО)

### Неделя 1: Гиперпараметр search

- Запустить поиск `scale_pos_weight` от 1 до 500
- Оценить Precision/Recall кривые
- Выбрать точку: Precision обналичивания > 60%

### Неделя 2: Валидация

- Переучить с выбранным параметром
- Проверить все классы (не испортились ли?)

**GO/NO-GO:**
- GO: обналичивание улучшилось И другие OK
- NO-GO: другие классы испортились
