# Task 5: Деградация модели и рычаги качества

---

## Что произошло?

После 2 месяцев работы в production (Sep-Oct 2024) точность модели упала:
- **Precision:** 72% → 58% (-14%)
- **Recall:** 85% → 72% (-13%)

Это **статистически значимая деградация**.

## Долгосрочное решение

**Проблема:** Data Drift будет продолжаться — появляются новые схемы.

**Решение:** Установить цикл переобучения:
- Каждый месяц: анализ деградации (как сейчас)
- Каждый квартал: переобучение на свежих данных
- Continuous: Feature Drift detection + auto-retrain pipeline

*(Подробно в отдельном ADR-006)*

## Когда делать Task 5?

**Это опциональное задание** для production модели, которая:
1. ✅ Прошла пилот (Фаза 1-3)
2. ✅ Запущена в production
3. ✅ Работает 1-2 месяца
4. ✅ Качество начало падать (Precision < 65%)

**Если качество стабильно > 75%:** Task 5 не требуется, просто плановые переобучения каждые 6 месяцев.
